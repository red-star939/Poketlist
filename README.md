## 🛠️ 인스톨러 빌드 안내

이 프로젝트는 [NSIS (Nullsoft Scriptable Install System)](https://nsis.sourceforge.io/)를 사용하여 인스톨러(`Poketlist_Setup.exe`)를 생성합니다.

1. NSIS 설치
2. 각 버전 폴더(`v0.1.2/` 등) 내의 `Poketlist.nsi` 스크립트를 NSIS로 컴파일하여 설치 파일 생성
