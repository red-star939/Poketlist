# Poketlist

Poketlist v0.1.0 배포 및 설치 스크립트 저장소입니다.

## 📦 다운로드 (Download)

최신 설치 파일(Setup.exe)은 [GitHub Releases](https://github.com/red-star939/Poketlist/releases/tag/v0.1.0)에서 다운로드할 수 있습니다.

- **버전**: v0.1.0
- **파일**: `Setup.exe`

## 📁 파일 구조

- `Poketlist.nsi`: NSIS 기반의 Windows 인스톨러 빌드 스크립트
- `README.md`: 프로젝트 및 배포 가이드 문서

## 🛠️ 인스톨러 빌드 안내

이 프로젝트는 [NSIS (Nullsoft Scriptable Install System)](https://nsis.sourceforge.io/)를 사용하여 인스톨러(`Setup.exe`)를 생성합니다.

1. NSIS 설치
2. `Poketlist.nsi` 스크립트를 NSIS로 컴파일하여 설치 파일 생성
